# CS509 Assignment 3 (Solo) — Minimum Spanning Tree

Individual task only: **Kruskal's** and **Prim's** MST algorithms on a
weighted, undirected CSR graph. (Gradient Descent and Maxflow-Mincut are
the buddy tasks and are not part of this solo submission.)

## IMPORTANT: folder layout required to build
This assignment does **not** keep its own copy of the CSR module.
It compiles directly against the real files inside `Assignment_01/src/`,
which must sit as a **sibling folder** next to this one:
```
your-repo/
├── Assignment_01/
│   └── src/
│       ├── csr.hpp        <- the file this assignment actually builds against
│       └── csr_shared.cpp
└── Assignment_03/          <- this folder
    ├── src/
    ├── tests/mst/
    └── Makefile
```
If `Assignment_01/src/csr.hpp` and `csr_shared.cpp` aren't present at that path,
this will fail to build.

## Build
```
cd Assignment_03
make            # builds assignment3.exe
make gen        # builds the optional graph_gen.exe test generator
```
Equivalent direct command (shown here so it's clear exactly which file is
being compiled from where):
```
g++ -O2 -Wall -Wextra -std=c++17 -I../Assignment_01/src \
    -o assignment3.exe \
    src/main.cpp ../Assignment_01/src/csr_shared.cpp src/mst_io.cpp src/mst_kruskal.cpp src/mst_prim.cpp
```

intentional, not missing files.

## CSR conversion — reused from Assignment 1 (by direct compile, not a copy)
Per the assignment's instruction to call the existing CSR conversion
function rather than reimplement it, this build:
- Adds `../Assignment_01/src` to the include path (`-I` flag), so
  `#include "csr.hpp"` in `mst_io.cpp` resolves to Assignment 1's real
  header, not a local copy.
- Compiles `../Assignment_01/src/csr_shared.cpp` directly as part of Assignment 3's
  build (see the `CSR_SRC` line in the Makefile) -- the exact same object
  code Assignment 1 uses, with zero duplicate source anywhere.
- `mst_io.cpp`'s `load_mst_graph()` parses the MST file format (no `SOURCE`
  line, unlike Bellman-Ford) into `degree`/`nbr`/`wt` vectors, then calls
  `adjlist_to_csr()` -- that conversion logic itself lives in exactly one
  place in the whole repo: `Assignment_01/src/csr_shared.cpp`.
- `undirected_E` (reported `E` in output/report) is `g.E / 2`, since
  `adjlist_to_csr()`'s `E` counts each undirected edge from both endpoints.

## Timing
Per the assignment's timing rule, only the algorithm itself is timed:
- File reading, parsing, and CSR conversion happen before `chrono` starts.
- For Kruskal, the edge-list extraction from CSR and the sort are inside
  the timed region (as required — that work happens inside the routine).
- Output printing happens after the timer stops.
